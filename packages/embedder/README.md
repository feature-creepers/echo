# @repo/embedder

A placeholder for the local embedding model that will turn text into vectors for memory search (docs/SPEC.md, section 10.3). It exports nothing yet, and nothing imports it.

- **Runs in:** Node
- **May import:** `@repo/core`, `@repo/models`
- **Entry points:** `@repo/embedder`

The import rule is enforced by `biome.jsonc` (docs/SPEC.md, section 14.3).
