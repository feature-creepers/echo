# @repo/speech

Speech recognisers and voices for each system, behind two interfaces that have the same shape on a device and on a server.

- **Runs in:** Node
- **May import:** `@repo/models`
- **Entry points:** `@repo/speech`

The import rule is enforced by `tooling/eslint/boundaries.js` and explained in [docs/SPEC.md](../../docs/SPEC.md), section 14.3.
