# @repo/store

The SQLite adapter: immutable records, keyword and vector search, files by content hash.

- **Runs in:** Node
- **May import:** `@repo/core`
- **Entry points:** `@repo/store`

The import rule is enforced by `tooling/eslint/boundaries.js` and explained in [docs/SPEC.md](../../docs/SPEC.md), section 14.3.
